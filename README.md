# 📝 Posts Viewer

Oddiy va tez ishlaydigan **Posts Viewer** — foydalanuvchilarga postlarni ko'rish va ular orasidan qidirish imkonini beruvchi veb-sahifa. Loyiha toza **HTML, CSS va JavaScript** asosida yaratilgan, hech qanday framework ishlatilmagan.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## 🚀 Xususiyatlari

- 📄 **Postlarni ko'rish** — API orqali barcha postlar ro'yxatini chiroyli formatda chiqarish
- 🔍 **Qidiruv (Search)** — sarlavha yoki matn bo'yicha real vaqtda postlarni filtrlash
- ⚡ Tez va yengil — hech qanday qo'shimcha kutubxonasiz sof JS
